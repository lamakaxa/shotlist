# SHOTLIST

**Симулятор карьеры фотографа с 3D-студией света — аналог set.a.light 3D, обёрнутый в карьерную игру.**

Ты берёшь заказы от агентств и журналов, арендуешь студию, ставишь свет, настраиваешь камеру и позу модели, снимаешь серию кадров и сдаёшь лучший. Чем точнее твоя схема света совпадает с брифом — тем выше гонорар и репутация. Направление вертикального среза: **Editorial / Fashion**.

## Что внутри

**Карьера.** Четыре заказа возрастающей сложности от разных клиентов (агентство Noir Models, журнал Haifa Edit, бренд Terra Wear, обложка RED NOIR). Каждый учит одной схеме света: бабочка → петля → рембрандтовский треугольник → editorial с контровым. За каждый сданный кадр — гонорар и репутация, открывается следующий заказ.

**3D-студия (ядро).** Настоящая 3D-сцена на Three.js с мягкими тенями в реальном времени:

- приборы: софтбокс, окто, стрип, бьюти-диш, рефлектор, фоновый;
- перетаскивание источников мышью прямо в сцене;
- мощность, цветовая температура (по Кельвину), растушёвка края, угол луча, высота, наклон;
- три вида: камера (как ляжет кадр), план сверху, свободная орбита.

**Манекен с риггингом.** Нейтральная грей-болванка со скелетом (голова, шея, корпус, 2 руки × плечо/локоть, 2 ноги × бедро/колено). Пресеты поз + **перетаскивание каждой конечности прямо в кадре**, повороты корпуса и головы.

**Камера.** ISO, выдержка, диафрагма, фокусное — с живой экспозицией (EV) и индикатором недо-/пересвета.

**Съёмка.** Серия из 5–7 кадров, контроль с процентом совпадения по брифу, выбор лучшего, сдача заказчику. Кнопка подсказки даёт наводку, если кадр далёк от задания.

Плюс свободная студия без задания.

## Как запустить

Игра — статическая страница, без сборки и зависимостей (Three.js подключается с CDN).

**Локально:**

```bash
# ES-модули не грузятся по file://, поэтому нужен локальный сервер
python3 -m http.server 8000
# открой http://localhost:8000
```

Или просто открой `index.html` в браузере (при наличии сети для CDN).

**Хостинг:** любой статический хостинг — GitHub Pages, Netlify, Vercel. Достаточно выложить все файлы, `index.html` в корне.

## Управление

| Действие | Как |
|---|---|
| Выбрать / добавить прибор | панель слева |
| Передвинуть источник | тянуть мышью в сцене |
| Высота источника | колесо мыши в виде «Сверху» |
| Поза модели | пресеты справа или тянуть конечности в кадре |
| Орбита камеры | тянуть фон в свободном виде |
| Снять кадр | кнопка внизу |

Поддержка клавиатуры, тача и мобильной раскладки. Без браузерного хранилища — прогресс в рамках сессии.

## Структура

```
index.html     — страница и весь UI (меню, доска заказов, студия)
game.js        — оркестрация: экраны, карьера, серия кадров, оценка
studio.js      — 3D-сцена: свет, камера, превью, скоринг по брифу
mannequin.js   — риггед-манекен со скелетом и IK-перетаскиванием
briefs.js      — данные заказов (балансовые числа схем света)
strings.js     — все тексты (локализация = замена этого файла)
logic.js       — заглушка игрового модуля (солописный режим)
```

## Стек

Ванильный JavaScript (ES-модули) + [Three.js](https://threejs.org/) для 3D. Ноль фреймворков, ноль сборки.
